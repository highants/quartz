# UV環境でのPythonアップデートの流れ

`uv` では「**PC全体で管理するPythonランタイム**」と「**プロジェクト（`.venv`）で使うPython**」の2段階に分かれています。

---

## 全体の流れ（チートシート）

| 手順 | コマンド | 内容 |
| :--- | :--- | :--- |
| **Step 0** | `uv self update` | `uv` 自体を最新バージョンに更新 |
| **Step 1** | `uv python list` | 利用可能なバージョンとインストール状況の確認 |
| **Step 2** | `uv python install 3.14 --upgrade` | 新しい Python を PC にインストール（マイナー指定推奨） |
| **Step 3** | `uv python pin 3.14` （プロジェクト内） | プロジェクトで使うバージョンを `.python-version` に固定 |
| **Step 4** | `uv sync` または `uv run ...` | 仮想環境（`.venv`）を新バージョンで自動再構築 |

---

## 各ステップの詳細

### Step 0. uv 本体のアップデート
```powershell
uv self update
```
※ 新しい Python バージョン（例: 3.14.x の新しいパッチリリースなど）は `uv` のバージョンアップによってインデックスに追加されることがあるため、最初に実行しておくと確実です。

---

### Step 1. インストール可能なバージョンを確認
```powershell
uv python list
```
- `<download available>` と出ているものはダウンロード可能。
- パスが出ているものは既にローカルにインストール済み。

---

### Step 2. 新しい Python をインストール
通常は **マイナーバージョン（3.14 など）** を指定して `--upgrade` を使うのが最もスムーズです。

```powershell
# 3.14 系の最新パッチ版を自動で取得・更新
uv python install 3.14 --upgrade
```

> **注意・Tips:**
> - `uv python install 3.14.10 --upgrade` のようにフルバージョンを指定すると `--upgrade` オプションでエラーになります（`--upgrade` はマイナー指定専用）。
> - `warning: Failed to install executable... use --force to replace it` という警告が出た場合は、グローバルのショートカット（`~/.local/bin/python3.14.exe`）を上書きするために `--force` を付けます：
>   ```powershell
>   uv python install 3.14 --upgrade --force
>   ```

---

### Step 3. プロジェクトの Python バージョンを切り替える
対象プロジェクトのディレクトリに移動して実行します。

```powershell
# 特定パッチに完全固定したい場合
uv python pin 3.14.10

# または、3.14系の最新に自動追従させたい場合（推奨）
uv python pin 3.14
```
※ これによりプロジェクト内の `.python-version` ファイルが書き換わります。

---

### Step 4. 仮想環境（.venv）を再構築して同期
バージョンを切り替えたら、仮想環境を新バージョンの Python で作り直します。

```powershell
# 仮想環境を再作成してパッケージを同期
uv sync --reinstall
```
※ `uv sync` や `uv run ...` を実行するだけでも、Python バージョンの不一致を検知して自動的に `.venv` を再作成してくれます。

---

## 便利なメンテナンスコマンド

```powershell
# 不要になった古いバージョンの削除
uv python uninstall 3.14.0
uv python uninstall 3.14.9

# 現在のプロジェクト環境の Python バージョン確認
uv run python -V
```
